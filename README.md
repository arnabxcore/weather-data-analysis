# 🌦️ Weather Data Analysis Using Pandas and NumPy

## 📌 Project Overview

This project analyses weather data using Python, Pandas, and NumPy. It explores temperature, humidity, and rainfall to demonstrate essential data analysis techniques.

The project uses a sample weather dataset for educational purposes.

## 🎯 Objectives

* Analyse temperature statistics.
* Identify the hottest and coldest days.
* Calculate average humidity and rainfall.
* Identify days with high temperatures.
* Analyse rainy days.
* Calculate daily temperature changes.
* Calculate a three-day moving average.
* Check for missing values.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy

## 📊 Dataset Description

The dataset contains the following columns:

| Column      | Description                    |
| ----------- | ------------------------------ |
| Date        | Date of observation            |
| City        | City name                      |
| Temperature | Temperature in degrees Celsius |
| Humidity    | Relative humidity percentage   |
| Rainfall    | Rainfall in millimetres        |

**Note:** The dataset contains sample data and does not represent verified historical weather observations.

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with your actual GitHub repository URL.

### 2. Open the project folder

```bash
cd weather-data-analysis
```

### 3. Install the required libraries

```bash
python -m pip install pandas numpy
```

### 4. Run the Python file

```bash
python weather_analysis.py
```
